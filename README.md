## 한국어

이 레포는 **blank 설치 파일만** 올리는 곳입니다. blank 의 소스는 공개하지 않습니다.

- **설치하기**: [Releases](https://github.com/yongilkim01/blank-releases/releases/latest) 에서 이 컴퓨터에 맞는 설치 파일을 받아 실행합니다.
  - Windows: `blank-setup-<버전>.exe`
  - macOS: `blank-<버전>-<arch>.dmg`
- **업데이트**: 설치된 blank 는 이 레포의 최신 릴리스에 있는 `latest.yml`(Windows) · `latest-mac.yml`(macOS)을 읽어 새 버전이 있는지 확인합니다. 새 버전이 있으면 창 오른쪽 아래에 알림이 뜹니다.
  - Windows 에서는 «업데이트» 를 누르면 새 버전을 받아 설치하고 다시 켭니다. 판에서 도는 에이전트는 멈추지 않습니다.
  - macOS 에서는 «받으러 가기» 가 이 페이지를 엽니다. 받은 파일로 지금 것 위에 덮어 설치하세요.
- 확인은 설정 › 일반 › 정보의 «자동으로 업데이트 확인» 으로 끌 수 있습니다.

## English

This repository holds **the blank installers only**. The sources of blank are not public.

- **Install**: download the installer for your machine from [Releases](https://github.com/yongilkim01/blank-releases/releases/latest) and run it.
  - Windows: `blank-setup-<version>.exe`
  - macOS: `blank-<version>-<arch>.dmg`
- **Updates**: an installed blank reads `latest.yml` (Windows) or `latest-mac.yml` (macOS) on the latest release here to learn whether a newer version is out, and shows a prompt at the bottom right of its window.
  - On Windows, "Update" downloads and installs the newer version and starts it again. Agents running in panes keep running.
  - On macOS, "Download" opens this page; install the downloaded file over the one you have.
- The check can be turned off with "Check for updates automatically" under Settings › General › About.
